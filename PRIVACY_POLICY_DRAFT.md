# Política de privacidad - Guarda Estados

Última actualización: [fecha de actualización]

## Nombre de la aplicación

Guarda Estados es el nombre provisional de esta aplicación.

## Función de la aplicación

Guarda Estados permite al usuario ver archivos de estado ubicados en una carpeta que autoriza mediante Android y guardar copias locales de imágenes o videos en el dispositivo.

## Funcionamiento local y cuentas

La aplicación funciona localmente en el dispositivo. No crea cuentas de usuario y no requiere iniciar sesión.

## Acceso a carpetas y permisos

La aplicación solo puede acceder a la carpeta que el usuario selecciona mediante el selector oficial de Android. Para recordar esa carpeta, usa el permiso URI persistente concedido por Android únicamente con ese fin.

El usuario puede cambiar la carpeta seleccionada o restablecer la configuración desde la aplicación.

## Datos a los que no accede

La aplicación no lee mensajes, contactos, notificaciones, llamadas, ubicación, cámara ni micrófono.

## Anuncios, consentimiento y servicios externos

La aplicación usa Google Mobile Ads para mostrar anuncios y Google User Messaging Platform (UMP) para solicitar y administrar el consentimiento cuando corresponde. Estos servicios pueden tratar identificadores del dispositivo o publicitarios, interacciones con anuncios, información de diagnóstico y otros datos técnicos según la configuración, el consentimiento del usuario y las políticas de Google.

La aplicación no usa Firebase ni integra analítica adicional propia. Las imágenes y videos de estados no se envían a Google ni a servidores de EstadoGo para almacenarlos o analizarlos.

Cuando UMP informa que las opciones de privacidad son necesarias, el usuario puede volver a abrirlas desde la sección de privacidad de la aplicación.

## Copias locales

Cuando el usuario guarda contenido, las copias se almacenan localmente en el dispositivo:

- Imágenes: Pictures/EstadoGo/Imágenes
- Videos: Movies/EstadoGo/Videos

Guardar una copia local no modifica los archivos originales.

## Compartir contenido

Cuando el usuario elige compartir contenido, la aplicación abre el selector oficial de Android para que el usuario decida con qué aplicación compartirlo. La aplicación no comparte contenido automáticamente.

## No afiliación

Guarda Estados no está afiliada a WhatsApp LLC, Meta Platforms, Inc. ni a otras aplicaciones compatibles.

## Responsabilidad del usuario

El usuario debe guardar o compartir contenido únicamente con autorización de su creador y respetando las leyes aplicables y los derechos de terceros.
